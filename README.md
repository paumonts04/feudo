# Feudo

Plataforma de running con conquista de territorio. Al completar una ruta cerrada,
el usuario conquista el área que queda dentro; si otro corre después por esa zona,
se la arrebata. Ranking por área conquistada.

Proyecto final de 2º de DAM.

## Tecnologías
- React + Vite
- Supabase (PostgreSQL, Auth y RLS)

## Entregas
- **v1 (diciembre 2026):** web con usuarios, roles, foro y moderación.
- **v2 (enero – junio 2027):** app móvil con GPS, mapa y conquista de territorio.
